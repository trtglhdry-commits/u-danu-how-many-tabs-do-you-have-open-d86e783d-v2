How Many Tabs Do You Have Open? — a program that writes one honest tab count to `entry.txt`: **365**. Not a hoarder's number picked to shock, and not the minimalist's `1`. Three hundred sixty-five — one tab opened every morning for a full year and never closed, a diary of a year kept in tabs. A believable count for a heavy tab user, surprising through the ritual it implies, and a whole habit in three digits.

## Run it

```sh
node main.ts
```

Writes the count to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Deterministic: the same three digits on every run.
